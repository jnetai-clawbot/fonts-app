### Project Structure

### Files Created
- settings.gradle - Project settings
- build.gradle - Root build file with Android Gradle Plugin 8.2.0 and Kotlin 1.9.22

- gradle/wrapper/gradle-wrapper.properties - Gradle 8.5 wrapper

### Kotlin Source Files
- DebugLogger.kt - Persistent error handling and logging system
- SettingsManager.kt - SharedPreferences-based settings manager
- FontManager.kt - 50+ decorative Unicode font converters
- SymbolManager.kt - 500+ special symbols
- EmojiManager.kt - 400+ emojis
- FontAdapter.kt - RecyclerView adapter for font list
- ReorderFontAdapter.kt - RecyclerView adapter for font reordering
- MainActivity.kt - Main activity with all features
- SettingsActivity.kt - Settings activity
- AboutActivity.kt - About activity with update check and share

### Features Implemented
- 50+ decorative Unicode fonts (Gothic, Typewriter, Comic, Script, Serif, Sans, Circles, Squares, Reverse, Double Struck, Small Caps, Bubble, Parenthesized, Fullwidth, Monospace, Tiny Letters, Strikethrough, Underline, Wavy, Dotted, Slash, Cross, Arrow, Heart, Star, Bridge, Smile, Thunder, Railway, Wheels, Track, Up Above, Sandwich, Fair, Bar, Waves, Sandra Peel, Heater, Seawave, Wall, Joiner, Wrapped, Box Packed, Outer Pack, Dot Packed, Corner, Joints, Directions, Star Join, Italic Bold, Italic Sans, Bold Fraktur, Currency, Warn, Birds, Rays, Magna, Fancy, Thin, Gloom, Paranormal, Coffee)
- Input text field with paste from clipboard
- Output text field with copy to clipboard (button + long press)
- Font list with preview (font name displayed in its own style)
- Favourite fonts system with dropdown filter
- Symbols panel (show/hide toggle) with 500+ clickable symbols
- Emojis panel (show/hide toggle) with 400+ clickable emojis
- Text transformations: Flip Up, Flip Down, Flip Left, Flip Right, Reverse
- Font size slider for output text
- Save/Load input and output text
- Custom font upload
- Settings: Dark/Light mode toggle, Animations toggle, Animation speed, Accent color picker, Font reorder
- About section: Version display, Check for Updates (GitHub API), Share App
- Animated button effects (customizable speed)
- Persistent error handling and debug logging throughout
